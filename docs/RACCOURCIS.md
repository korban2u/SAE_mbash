# Raccourcis clavier dans mbash

## Navigation
- Flèches gauche/droite : Déplacer le curseur
- Home/End : Aller au début/fin de ligne
- Flèches haut/bas : Naviguer dans l'historique

## Édition
- Tab : Compléter la commande/chemin
- Backspace : Supprimer le caractère précédent
- Ctrl+C : Interrompre
- Ctrl+D : Quitter (EOF)
